# Leonida Ledger

An offline field guide and checklist for all 55 Grand Theft Auto VI PS5 trophies. Each entry gives the official requirement, a cited unlock guide and a verdict on availability. The platinum roadmap puts the Chapter 1 meditation warning up front and groups the full 100% completion targets by activity.

Open `app/index.html` in desktop Chrome, or run `node serve.ts` and visit `http://127.0.0.1:8080/`. The guide has no install or build step. Earned checks, notes and the story shield are saved per browser origin; use Export and Import to transfer them. Import replaces the current ledger. Source links go online only when followed.

Guide wording and local artwork are original to this entry. Official strings come from the make.fun starter; walkthrough facts come from the PowerPyx pages cited in the app. The Chapter 1 meditation’s necessity, four of the eight qualifying stranger strands, the exact animal for Fair Game, and the required lab count for Tyrone’s follow-up remain unconfirmed in the sources used.

To edit the catalog, update `app/data/trophies.json` and run `node sync-catalog.mjs` to refresh the checked-in browser copy. `MAKEFUN_OUTPUT_DIR=out node main.ts` packages the static app, screenshots and make.fun dossier with Node 22.18+.
